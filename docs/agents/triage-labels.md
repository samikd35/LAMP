# Triage labels

| GitHub label | Meaning |
| --- | --- |
| `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | The reporter needs to provide more information. |
| `ready-for-agent` | The work is specified and ready for an agent. |
| `ready-for-human` | The work requires a human to implement it. |
| `wontfix` | The team has decided to close the request without implementing it. |
