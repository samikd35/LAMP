# Issue tracker

The Pixared spec and implementation tickets live in GitHub Issues for `samikd35/LAMP`. Target that repository explicitly when using the GitHub connector, CLI or API. [Issues](https://github.com/samikd35/LAMP/issues)

Publish the spec as a parent issue and each approved ticket as a sub-issue. Link dependencies using GitHub’s blocking relationships. If a relationship is unavailable, reference the parent or blocker by issue number in the ticket body. Apply `ready-for-agent` when the work is fully specified. Use the issue’s description and comments when implementing it.

**PRs as a request surface: no.**
